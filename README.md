# Smart Animal Monitoring Collar

An AI-enabled animal health monitoring system that combines IoT sensors and deep learning to support real-time health monitoring and early detection of potential health concerns in cats and dogs.

## Project Overview

The project integrates a smart wearable collar with a digital application to collect and monitor animal health data. The system is designed to track key health and location indicators while also providing an AI-based feature for image classification of skin conditions.

## Key Features

- Real-time heart rate and SpO2 monitoring
- Body temperature monitoring
- GPS location tracking
- Movement monitoring
- AI-based skin condition classification
- Health alerts and remote monitoring
- Animal profiles and vaccination reminders

## AI & Deep Learning

Deep learning models were explored for image-based classification of skin conditions:

- **Xception** for dog skin condition classification
- **EfficientNet-B0** for cat skin condition classification
- Image preprocessing and model evaluation were performed as part of the development process

## Technologies

- Python
- Deep Learning
- Xception
- EfficientNet-B0
- IoT
- ESP32
- Health Monitoring Sensors
- GPS

## Project Purpose

The project explores how AI and IoT technologies can work together to provide continuous animal health monitoring and support earlier identification of potential health concerns.
