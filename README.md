# Smart Animal Monitoring Collar

An AI-enabled IoT system designed to monitor animal health and activity using wearable sensors and a mobile application.

## Overview

Smart Animal Monitoring Collar is a technology-based solution that combines IoT, mobile application development, and Artificial Intelligence to support animal health monitoring.

The system is designed to collect and display animal health and activity data through connected sensors and provide intelligent insights through the application.

## Key Features

- Heart rate monitoring
- Blood oxygen (SpO₂) monitoring
- Body temperature monitoring
- Activity and movement monitoring
- GPS location tracking
- Animal profile management
- Health data monitoring
- AI-based skin condition classification
- Veterinary support features

## Technology Stack

- Flutter
- Dart
- ESP32
- IoT Sensors
- Artificial Intelligence
- Deep Learning
- Python

## System Components

The proposed system consists of:

1. Smart wearable collar
2. Health and motion sensors
3. ESP32 microcontroller
4. Mobile application
5. AI-based analysis component

## Project Goal

The goal of the project is to provide a smart and connected approach to animal health monitoring by combining IoT sensing, mobile technologies, and Artificial Intelligence.

## Project Status

Academic graduation project.

## Future Development

Future improvements may include expanding the AI models, improving health-data analysis, enhancing real-time monitoring, and integrating additional veterinary features.
